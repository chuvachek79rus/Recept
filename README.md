# Рецепт в кармане

Отдельное русскоязычное mobile-first приложение: превращает публичные описания роликов, текст и субтитры в структурированные рецепты. Проект не связан с приложением «Мой Дневник Питания».

## Что работает

- Главная, библиотека с поиском, категориями и избранным.
- Импорт по ссылке, загрузка видео, вставка текста/субтитров.
- Экран проверки: редактирование полей, ингредиентов и шагов до сохранения.
- Карточка рецепта, пересчёт порций, отметки выполненных шагов.
- Приблизительный КБЖУ по локальному справочнику продуктов. Неизвестные продукты явно перечисляются и не выдумываются.
- Общий список покупок с объединением одинаковых позиций.
- Локальное хранение, JSON экспорт/импорт, пользовательские категории.
- PWA manifest, иконки и Android `share_target` для ссылки/текста.

## Архитектура

- **TanStack Start + React 19 + TypeScript** — страницы, SSR и серверные маршруты.
- **Tailwind CSS v4** — токены оформления в `src/styles.css`.
- **`src/lib/recipes/`** — типы, детерминированный парсер, справочник продуктов, расчёт КБЖУ, пересчёт порций и локальный репозиторий.
- **`src/routes/api/recipes/`** — адаптеры импорта URL, текста и видео.
- **`src/lib/server/providers.ts`** — единая точка подключения внешнего inference-сервиса.
- **`localStorage`** — рецепты, покупки и настройки; **`sessionStorage`** — черновик между импортом и проверкой. Аккаунт и облачная база не используются.

Слой хранения вынесен в интерфейс `RecipeRepository`, поэтому позже его можно заменить облачной реализацией без переписывания экранов.

## Локальный запуск

Нужны Bun и современный Node.js.

```sh
bun install
bun run dev
```

Проверки:

```sh
bunx vitest run
bun run build
```

Сборка должна завершиться без ошибок до публикации или упаковки Android-оболочки.

## Установка как PWA на Android

1. Опубликуйте приложение на HTTPS-домене.
2. Откройте его в Chrome на Android.
3. В меню Chrome выберите **«Установить приложение»** или **«Добавить на главный экран»**.
4. После установки в системном меню **«Поделиться»** выберите «Рецепт в кармане»: ссылка или текст откроются на экране импорта.

`share_target` находится в `public/manifest.webmanifest`. Поддержка зависит от браузера и способа установки. Офлайн-кэш и service worker намеренно не добавлены: приложение не заявляет полноценную работу без сети. Сохранённые данные локальны, но для первоначальной загрузки и серверного импорта нужен интернет.

## Ограничения ссылок и видео

Приложение не обходит вход, приватность или ограничения Instagram/TikTok и не скачивает ролики в обход правил платформы. По URL читаются только доступные публичные метаданные и описание. Если полноценного рецепта там нет, интерфейс просит загрузить файл или вставить текст/субтитры.

Без `INFERENCE_URL` загрузка видео возвращает честный статус `inference_not_configured`; выдуманный результат не создаётся. Текст без внешнего сервиса обрабатывает детерминированный демо-парсер, и результат всегда помечается как демо.

## Бесплатный внешний inference endpoint

Можно самостоятельно разместить сервис на базе открытых моделей, например faster-whisper для речи и Qwen3-VL для кадров/структурирования. Платные API и OpenAI не подключены.

Переменные окружения:

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `INFERENCE_URL` | Нет | Базовый HTTPS-адрес самостоятельно размещённого сервиса, без завершающего `/`. |
| `INFERENCE_TOKEN` | Нет | Bearer-токен для этого сервиса. Добавлять только через секреты окружения, не в код. |

Сервис должен поддерживать:

- `POST /parse-text` — JSON `{ "text": string, "source_url": string | null, "title"?: string }`.
- `POST /analyze` — `multipart/form-data` с `file` и необязательным `source_url`.
- Оба ответа должны соответствовать `analysisResultSchema` из `src/lib/recipes/types.ts`.

Тайм-ауты: 60 секунд для текста и 300 секунд для видео. Максимальный размер видео — 50 МБ; текста — 20 000 символов. При недоступности текстового сервиса используется демо-парсер с предупреждением. Ошибка видео-сервиса не подменяется демо-рецептом.

## Android-оболочка Capacitor

В проект добавлены Capacitor **8.6.2**, конфигурация `capacitor.config.ts` и нативный проект `android/`. Используются Node.js 22+, Android SDK 36, Gradle 8.14.3 и Android Gradle Plugin 8.13.0; для локальной сборки нужны Android Studio и JDK 17.

**APK пока не собран.** `server.url` указывает на production-адрес этого приложения: `https://recept-v-karmane.lovable.app`. Не заменяйте его на localhost, временный preview или чужой сайт.

### Почему выбран удалённый режим

TanStack Start выполняет импорт через серверные маршруты `/api/recipes/*`. Android-оболочка загружает опубликованный сайт, поэтому эти маршруты продолжают работать на сервере. `dist/client` указан как обязательный `webDir` для Capacitor CLI, но **не является автономной версией приложения**. Для работы оболочки нужны интернет и доступный production-сервер.

SSR-сборка TanStack Start не создаёт статический `index.html`, поэтому `scripts/prepare-capacitor.mjs` добавляет в нативную сборку техническую заглушку из `capacitor-shell/index.html`. Она лишь открывает тот же production URL и не заменяет серверное приложение.

Не удаляйте `server.url` и не упаковывайте только `dist/client`: локальная WebView сама не выполнит серверные маршруты. Полностью автономный режим потребует отдельного переноса импорта на устройство или в публичный HTTPS API.

### Подготовка и синхронизация

1. Production-адрес уже задан в `capacitor.config.ts`: `https://recept-v-karmane.lovable.app`. Перед сборкой проверьте, что опубликованная версия содержит нужные изменения.
2. Для выпуска в магазин замените примерный `appId` `ru.example.receptvkarmane` на собственный идентификатор.
3. Установите зависимости и проверьте веб-приложение:

```sh
bun install
bunx vitest run
bun run build
```

4. Выполните сборку веб-ресурсов и синхронизацию нативного проекта:

```sh
bun run android:sync
```

Команда эквивалентна `vite build && node scripts/prepare-capacitor.mjs && cap sync android`. При использовании npm: `npm run android:sync`.

5. Откройте проект в Android Studio:

```sh
bun run android:open
```

Либо откройте каталог `android/` вручную и дождитесь Gradle Sync. В SDK Manager должен быть установлен Android SDK 36.

### Сборка debug APK

После успешной синхронизации на macOS/Linux:

```sh
bun run android:assemble
```

Или одной командой — повторная синхронизация и сборка:

```sh
bun run android:apk
```

На Windows используйте Android Studio либо выполните `gradlew.bat assembleDebug` в каталоге `android/`. Debug APK появится по пути:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Для release APK в Android Studio выберите **Build → Generate Signed App Bundle / APK… → APK**, создайте или выберите хранилище ключей и запустите подписанную сборку. Не коммитьте keystore, пароли и токены. Debug APK не является подписанным release-артефактом для магазина.

### Нативное «Поделиться»

PWA `share_target` автоматически не становится Android Intent внутри Capacitor. Нативный приём ссылок и текста пока не настроен: для него отдельно потребуются intent-filter, совместимый Share Intent plugin и обработчик входящих данных. Сейчас в Android-оболочке доступны вставка ссылки, загрузка файла и ввод текста вручную.

## Приватность и ограничения расчётов

Рецепты и покупки остаются в браузере устройства до экспорта. Загруженное видео не сохраняется приложением: оно пересылается настроенному inference-сервису в памяти запроса. КБЖУ — справочная оценка, а не медицинская рекомендация; объёмы, штуки и неизвестные продукты снижают точность.
